# Java Practice Codes

Java coursework and programming exercises by **Adeeb Sharar**, a Computer Science and Engineering student at United International University.

This repository collects my current Java practice source files. It is a learning archive rather than a single application.

## Contents

- **practice/src/**: exercises on classes and objects, arrays, ArrayList, methods, constructors, inheritance, and basic Swing interfaces.
- **hello-world/**: a separate introductory Maven project, preserving its original source and build settings.
- **FILE_INDEX.md**: complete source-file list.

## Run an exercise

Open the relevant source folder or Maven project in your Java IDE. Choose the class containing a main method and run that exercise with its required helper classes.

Some files reuse class names or contain work in progress. Do not compile all exercises together as one application. The original source files and Java package names are preserved; existing compile issues have not been silently rewritten.

For a standalone example from practice/src:

```text
javac Circle.java
java Circle
```

Only use that command if the selected class has its own main method. For packaged examples, compile and run from the corresponding source root using the declared package name. The introductory Maven project's original pom.xml targets Java 24.
